مساعدي المحاسبي - حزمة PWA

هذه الحزمة أصبحت مهيأة كتطبيق ويب قابل للتثبيت (PWA).
لتثبيتها على Android يجب أولاً نشر محتويات هذا المجلد على عنوان HTTPS. يمكن استخدام GitHub Pages مجاناً.

الخطوات المختصرة:
1) أنشئ مستودع GitHub جديداً وارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
2) من Settings > Pages اختر النشر من الفرع الرئيسي (main) ومجلد /(root).
3) افتح رابط GitHub Pages الناتج على هاتف Samsung A15 باستخدام Chrome.
4) من قائمة Chrome اختر Install app أو Add to Home screen ثم Install.
5) افتح التطبيق من الأيقونة. بعد أول تحميل ناجح يمكن فتح الملفات المخزنة دون اتصال.

مهم: فتح index.html مباشرة من مدير الملفات لا يفعّل PWA أو Service Worker. يلزم HTTPS أو localhost.
البيانات المحفوظة محلياً قد تضيع عند مسح بيانات المتصفح؛ احتفظ بنسخة JSON احتياطية دورياً.
